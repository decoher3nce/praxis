# Session Templates

*Fill-in scaffolds for the four recurring conversation types. Keep them light. They're prompts to keep you honest, not scripts to read aloud. Talking points for each phase live in `01-coach-guide.md`.*

*Reminder: any filled-in copy with real names and content belongs in your organization's approved systems, not in this template kit.*

---

## A. Contracting session

**Goal:** opt-in agreement, honest framing of the dual role, and a shared sense of cadence.

```
Date: __________   Student: __________

1. Frame the invitation (gift, not flag)
   - Said clearly that this is development, not correction: ☐
   - Said clearly that declining is cost-free: ☐

2. Name the dual role honestly
   - Explained what stays in the coaching space: ☐
   - Explained what may cross to the record, and that I'll flag it in the moment: ☐
   - Student's reaction / concerns:
     _______________________________________________

3. Their "why"
   - What would make this worth their time?
     _______________________________________________
   - What do they want to be true in ~3 months?
     _______________________________________________

4. Logistics
   - Cycle length: __________   Cadence: __________

5. Decision this cycle
   ☐ Opting in   ☐ Passing this cycle (revisit: __________)

6. Expectations handout walked through together (02-coaching-expectations.md): ☐
```

## B. Selection & path-build session

**Goal:** present a few, student chooses one (or passes), readiness check, build the path.

```
Date: __________   Student: __________

1. Dimensions presented (a few, with specific evidence for each; add/remove rows as needed)
   a. __________   evidence: __________________________
   b. __________   evidence: __________________________
   c. __________   evidence: __________________________
   (Or: student brought their own → __________________)

2. Choice
   ☐ Chose: __________   ☐ Passed this cycle (revisit: ______)

3. Readiness check (03-readiness-and-timing.md)
   - Relevance: where will they practice this for real?
     _______________________________________________
   - Bandwidth: do they have room? (honest read)
     _______________________________________________
   - Verdict: ☐ Go   ☐ Wait   ☐ Swap dimension

4. Pre-rating (05-reflection-2x2.md)
   - Self rating: ____   Coach rating: ____
   - Quadrant: ____________________________________

5. Path built (from the dimension file, tailored to real work)
   - Learning path chosen: ________________________
   - Activity 1 anchored to: ______________________
   - Next visible-stretch candidate: ______________
```

## C. Check-in session

**Goal:** debrief the latest activity (retrieval, not review) and decide keep / tweak / swap.

```
Date: __________   Student: __________   Dimension: __________

1. Debrief by reconstruction (no rereading notes)
   - What actually happened?
     _______________________________________________
   - Where did it go differently than expected?
     _______________________________________________
   - What did they notice about themselves?
     _______________________________________________
   - One thing they'd change next time?
     _______________________________________________

2. Did this produce learning or just activity?
   ☐ Learning   ☐ Mostly activity

3. Decision
   ☐ Keep (run again / space it out)
   ☐ Tweak (adjust difficulty, scope, or framing): __________
   ☐ Swap (replace the activity): __________
   ☐ Pause (bandwidth/timing): revisit __________

4. Next action + when:
   _______________________________________________
```

---

## D. Closing session

**Goal:** re-rate, name the movement, decide what's next (continue / switch / graduate).

```
Date: __________   Student: __________   Dimension: __________

1. Post-rating (05-reflection-2x2.md)
   - Self: ____   Coach: ____   Quadrant: __________
   - Movement from pre → post: ___________________

2. Name the specific movement / change observed
   _______________________________________________

3. What's next?
   ☐ Continue this dimension (more reps)
   ☐ Switch to a new dimension next cycle
   ☐ Graduate → student coaches someone else in this dimension
       - Candidate to coach: __________
       - How I'll support their coaching: __________
   ☐ Close engagement for now

4. Closing note / what to celebrate:
   _______________________________________________
```
