# Tracking Template: One Coaching Cycle

*An optional, blank log for a single Praxis cycle: which dimension, the dates, what was tried, and how the 2×2 moved. Use it if it helps you stay honest about the loop; skip it if it becomes overhead.*

> **Data placement note.** This is a blank template. Any filled-in version (with a real person's name and real coaching content) is per-person performance-adjacent data and belongs in your organization's **approved systems**, not in this kit and not in a personal vault. Keep the template clean; keep the record where it's governed.
